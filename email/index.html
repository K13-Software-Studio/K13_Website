K13 email signatures

Five signatures, from the full one to plain text, each shown on a light and a dark inbox. Pick your mail app, then Copy puts the right version on your clipboard.

Email on the signature

Set it up in Gmail

  1. Gmail → Settings (the gear) → See all settings → General → Signature.
  2. Create new, give it the name shown on the card (K13SS new, K13SS compact...), click into the box, press Cmd+V.
  3. Under Signature defaults pick one for new emails and one for replies (suggested: K13SS new and K13SS inline). Save Changes at the bottom.
  4. While writing any email, the pen icon in the bottom bar switches signatures.
  1. Copy with the Copy button on this page, in Chrome. Do not select the signature with the mouse, and do not copy from Safari: Safari's copy enlarges the logo.
  2. Mail → Settings (Cmd+,) → Signatures. Pick the account on the left, press + and name it as on the card (K13SS new...).
  3. Before pasting, untick “Always match my default message font” under the box. Left ticked, Mail rewrites the fonts and colours.
  4. Click into the box on the right, press Cmd+A then Delete to clear Mail's default text, then Cmd+V.
  5. The logo can show as a blue question mark inside Settings. That is normal: close Settings, open a new email and it is there.
  6. Pick the default under the box with “Choose Signature”. In Settings → Composing, Message format must be Rich Text.
  7. iPhone Mail drops pictures from a pasted signature: use K13SS text there.
  1. Copy with the Copy button on this page (the Outlook version, picked above: it carries the extra code Outlook for Windows needs).
  2. Outlook on Mac, new Outlook on Windows and outlook.com: Settings → Signatures (on the web: Settings → Account → Signatures). Classic Outlook on Windows: File → Options → Mail → Signatures.
  3. Press + (or New), name it as on the card, click into the box and press Cmd+V (Ctrl+V on Windows).
  4. If the text turns plain after pasting, click the small clipboard icon that appears beside it and choose “Keep Source Formatting”.
  5. Set the defaults for new messages and for replies (suggested: K13SS new and K13SS inline), then Save.
  6. Classic Outlook stores the logo inside the signature, so it shows without “download pictures”. That is expected.
